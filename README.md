## 🎯 Tracks Overview

### 1. 🐍 Python Full Stack
* **Phase 0:** Language Foundations, Data Structures, OOP, Advanced Python (Days 01–10)
* **Phase 1:** Data Analyst Core (NumPy, Pandas, Matplotlib, Seaborn, SQL) (Days 11–20)
* **Phase 2:** Full Stack Web Backend (FastAPI, SQLAlchemy, PostgreSQL, Docker) (Days 21–25)
* **Phase 3:** Machine Learning & Data Science (scikit-learn, PyTorch) (Days 26–30)
* **Phase 4:** AI Engineering (LLMs, RAG, LangChain, AI Agents) (Days 31–35)

### 2. 🧮 Data Structures & Algorithms (DSA)
* **Every problem solved in both Python 3 AND Java.**
* Clear progression: **Brute Force $\rightarrow$ Optimal Pattern**.
* Includes Time Complexity, Space Complexity, and line-by-line intuition breakdown.
* Top patterns covered: Arrays, Two Pointers, Sliding Window, Hashmaps, Binary Search, Stacks, Linked Lists, Trees, Graphs, DP.

### 3. ⚡ Modern JavaScript
* ES6+ primitives, scope chains, execution context, closures.
* Modern array manipulation (`map`, `filter`, `reduce`).
* Asynchronous JS: Event Loop, Microtask Queue, Promises, `async`/`await`, Fetch API.
* Transition to React, Tailwind CSS, and Full Stack integration.
